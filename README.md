# My First Repo

This repository contains a small Python project developed during Lab 2 to practise Git and GitHub.

## How to run

Run the Python script using the following command:

```
python greetings.py
```

## What's inside

- `greetings.py`: a Python script containing different greeting functions (`greet`, `farewell`, `shout`, `thank_you`, and `goodnight`).
- `motto.txt`: a text file used to practise branching and resolving merge conflicts.
- `lunch.txt`: a file used to practise resolving merge conflicts.
- `.gitignore`: specifies which files Git should ignore.

## What I learned

During this lab, I learned how to use Git and GitHub to manage different versions of a project and collaborate with others.

The main Git commands I learned are:

- `git init`: initializes a new Git repository.
- `git status`: shows the current state of the repository and any uncommitted changes.
- `git add`: stages changes before committing them.
- `git commit`: saves changes in the repository's history.
- `git merge`: combines changes from different branches.
- `git revert`: creates a new commit that undoes a previous commit.
- `git clone`: downloads a copy of a remote repository.
